How to read this
  • One row per report whose content changed. Identical repeats are folded into the row as ×N.
  • Bold rows are meaningful to the wall: state, progress, layer, error, speed profile, door, job name, time left.
  • Dim ticking rows are sensor jitter: temperatures, fans, Wi-Fi. They are folded by default.
  • Each row ends with wall → the state the wall derives from the reports up to that one. It is historical: it never borrows the printer’s current state.
  • View raw report on any row shows the full redacted report. Serials, addresses, access codes and private URLs are removed before it leaves the Pi.
  • The Pi keeps the last 400 reports per printer in memory; older history is not stored anywhere.
