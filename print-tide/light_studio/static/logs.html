HOW TO READ THIS
  • One row per report whose content changed. Identical repeats are folded into the row as ×N.
  • Bold rows are meaningful to the wall: state, progress, layer, error, speed profile, door.
  • Dim ticking rows are sensor jitter: temperatures, fans, Wi-Fi. Hide them with the checkbox.
  • Each row ends with wall → the state Print Tide derives from that report and the animation it plays.
  • Click a row to see the full raw print payload of that report (serials, addresses and URLs are removed before it leaves the printer object).
