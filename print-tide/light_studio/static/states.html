Every colour any state can produce comes from these keys. Change the theme in the Studio's Animation lab and Save & apply to recolour the wall.

Each rope is 100 positions: 90 for state, the last 10 an always-on accent cap. The controller takes about 24 messages per second per rope, so every animation is built as a still base plus a few narrow moving parts; a full-strip gradient would tear. Previews are amplified for the screen and are not a photometric match to the LEDs.
